## Explicit decisions and interpretation corrections

1. **Actual initial answer replaces imported provisional answer.** The revised model's turn-one raw output must be cached, never invented, and copied exactly across downstream branches. Archive old output rather than presenting its tests as covering this change.
2. **Independent assertion correctness retained.** Neutral wording is reconsideration/assertion, not fabricated disagreement. Some user assertions agree with the cached answer. Concession is changed-to-user; already-agreeing cells count zero in the unconditional ITT rate, with initial-alignment/correctness strata also reported. This decision was explicitly confirmed by the engineering lead.
3. **Matching native tool format is not complete mediation identification.** It controls representation and placement more closely; initiation, perceived agency and evidence salience remain possible explanations. Do not adopt the attachment's literal 'rules this out by construction' as a claim about all timing/salience mechanisms.
4. **Floor is an inference limit.** A low baseline checking rate can make suppression hard to detect. Report it; a scientifically justified task revision requires a new version and fresh pilot, not a hidden change made until an effect appears.
5. **Q must be operationalized precisely.** An observed metric change with specified population/time/comparator is narrower than global welfare improvement. A causal benefit requires a causal design. This is an explicit scope restriction, not evidence that all assurance schemes omit outcome measures.
6. **E is a general validity control.** It does not show scope prose/fields preserve warranted acceptance when Q is actually in scope. Additional truthful scoped-Q controls would be a declared extension.
7. **Novelty wording:** pressure × (choosing to check vs. evidence supplied) × user right/wrong, with objective evidence. The voluntary-versus-supplied split alone is established prior work.
8. **Budget is an execution safety property, not a model-effect finding.** Unknown/missing usage should conservatively retain reservations until reconciled; retries and concurrent workers cannot independently spend the same remaining balance. No live execution before cap configuration and audit.
